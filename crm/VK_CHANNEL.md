# ВКонтакте — как запустить канал

## Коротко

- Делаем **публичную страницу** «Автопарк Контроль | автоматизация бизнеса».
- Контент уже готов: `crm/vk_content_plan.md` — 23 поста, по одному в день, 10:00 по Красноярску.
- Если добавишь новые посты в MAX-очередь, пересобери VK-план: `python3 crm/build_vk_queue.py`.
- Автопостинг через VK API — как бонус. VK с 2024 ужесточил `wall.post`: официально нужен ключ пользователя с правом `wall`, а его выдают не всем. Ключ сообщества подходит для сообщений, но для стены может вернуть ошибку доступа.
- Поэтому основной путь — **таймер в VK**: копируешь пост из плана и ставишь дату. Это работает всегда.
- Если токен сработает — `crm/vk_channel_publish.py` опубликует пост сам.

## 1. Создать сообщество

1. В VK: «Создать сообщество» → «Публичная страница».
2. Название: `Автопарк Контроль | автоматизация бизнеса`.
3. В описание добавь:
   - Сайт: https://r1aven15.github.io/logist_mvp/
   - Презентация: https://r1aven15.github.io/logist_mvp/offer-krsk.html
   - Демо: https://r1aven15.github.io/logist_mvp/demo-krsk.html
   - МАКС: https://max.ru/se15129408_bot
4. Загрузи логотип из `brand/logo-icon.png`.
5. Создай тему оформления в спокойных цветах, без «кричащих» баннеров.

## 2. Узнать ID сообщества

Открой сообщество → «Управление» → «Настройки». В адресе будет `vk.com/club123456` или `vk.com/public123456`. Число после `club`/`public` — это `VK_GROUP_ID`.

## 3. Получить ключ доступа сообщества

1. Сообщество → «Управление» → «Дополнительно» → «Работа с API».
2. Вкладка «Ключи доступа» → «Создать ключ».
3. Права: `wall`, `manage`, `photos` (если будешь публиковать фото).
4. Подтверди по СМС или в приложении VK.
5. Скопируй токен. **Не отправляй его в чат и не коммить в GitHub.**

Если VK не даёт право `wall` или `wall.post` возвращает ошибку 15/214 — не трать время, переходи к ручному таймеру. Это нормальное ограничение VK, а не ошибка настройки.

## 4. Куда положить токен

### Локально

В `outreach/.env` (файл уже в `.gitignore`):

```env
VK_GROUP_ID=123456
VK_ACCESS_TOKEN=твой_токен
VK_ATTACHMENT_URL=https://r1aven15.github.io/logist_mvp/offer-krsk.html
```

### GitHub Actions

Settings → Secrets and variables → Actions → New repository secret:

- `VK_ACCESS_TOKEN`
- `VK_GROUP_ID`

Секреты GitHub не видны в публичном репозитории.

## 5. Проверить

```bash
python3 crm/vk_channel_publish.py --list
python3 crm/vk_channel_publish.py --index 1 --dry-run
python3 crm/vk_channel_publish.py --index 1 --send
```

Если `--send` вернул ошибку доступа:

- открой `crm/vk_content_plan.md`;
- публикуй вручную через таймер VK;
- не повторяй `--send` много раз, чтобы VK не воспринял это как спам.

## 6. Ручной график

- 1 пост в день, 10:00 по Красноярску.
- Первый пост закрепи.
- Чередуй темы: боль → кейс → чек-лист → продукт → предложение.
- В каждом посте есть ссылки на презентацию, демо и МАКС.
- Раз в 2–3 дня делай репост записи сообщества на свою личную страницу: «Поделиться» → «На свою страницу». Так знакомые увидят пост, но лента не будет забита.

## 8. Бот в VK

Бот для входящих сообщений — отдельная история. Ему нужен Callback API или Long Poll и сервер, который всегда онлайн. Для старта канала бот не обязателен: в постах уже есть ссылка на МАКС-бот, где можно написать «ПИЛОТ».

Если захочешь бота в VK — сделаем позже: автоответ на «ПИЛОТ», вопросы по цене, демо и презентации.

## 9. Автоматизация

В репозитории есть `.github/workflows/vk-channel.yml` с ручным запуском. После добавления секретов можно включить расписание. Но если VK не даст `wall.post`, оставляем ручной таймер — контент-план уже готов.

## Безопасность

- Токен VK — только в `outreach/.env` или GitHub Secrets.
- Если токен попал в переписку или скриншот — отзови его в настройках сообщества и создай новый.
- Не публикуй `secrets/`, `.secrets/`, `data/`, `crm/.env`, `outreach/.env`.
