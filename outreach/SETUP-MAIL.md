# Как привязать почту

Нужен отдельный ящик для деловых писем. Обычный пароль от почты в скрипт
не подходит — нужен «пароль приложения» для SMTP.

## Яндекс

1. Войдите в https://id.yandex.ru.
2. Откройте «Безопасность» → «Пароли приложений».
3. Создайте пароль для «Почта» (или «Другое» → `Autopark Control`).
4. Скопируйте пароль один раз — он понадобится в `.env`.
5. В настройках почты включите доступ по IMAP/SMTP, если он выключен.

Настройки:

```text
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_MODE=ssl
SMTP_USER=ваш-ящик@yandex.ru
SMTP_PASSWORD=пароль-приложения
SMTP_FROM=ваш-ящик@yandex.ru
SMTP_NAME=Ваше имя
```

## Mail.ru

1. Войдите в почту на https://mail.ru.
2. Откройте https://account.mail.ru/settings/security.
3. Найдите «Пароли для внешних приложений» и создайте пароль для почтового клиента.
4. Если есть пункт «Доступ к почтовому ящику по протоколу IMAP/SMTP» — включите его.
5. Настройки: `smtp.mail.ru`, порт `465`, режим `ssl`.
6. В `.env` укажите полный адрес в `SMTP_USER` и `SMTP_FROM`, а в `SMTP_PASSWORD` — пароль приложения, не обычный пароль от почты.

Проверка:

```bash
python outreach/test_smtp.py
```

## Gmail

1. Включите двухэтапную аутентификацию.
2. https://myaccount.google.com/apppasswords → создайте пароль приложения.
3. Настройки: `smtp.gmail.com`, порт `587`, режим `starttls`.

Gmail хуже подходит для холодных писем: чаще попадает в спам. Для рассылки
по Красноярску лучше отдельный ящик на домене или Яндекс/Mail.ru.

## Проверка без отправки письма

Заполните `.env`, затем:

```bash
python outreach/test_smtp.py
```

Скрипт только подключается к SMTP и проверяет логин. Письма не отправляет.

## Что не делать

- Не вставляйте пароль в `index.html`, `demo.html` или Android-приложение.
- Не отправляйте `.env` в чат, на почту или в git.
- Не используйте основной личный ящик: отдельный ящик проще отключить,
  если пойдёт спам или жалобы.
- Не покупайте базы адресов. Пишите только тем, кто может быть заинтересован,
  и уважайте ответ «нет».
