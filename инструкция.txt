# ПРОЕКТ: Газель-Контроль

## Описание
Веб-приложение для учёта ТО, рейсов и топлива парка автомобилей «Газель». 
Работает на связке: HTML (фронтенд) + Python Flask (бэкенд на Render) + Firebase (база данных) + ГЛОНАССSoft (телеметрия).

## Стек технологий
- Фронтенд: Один файл index.html (HTML + CSS + Vanilla JS).
- Бэкенд: Python 3, Flask, библиотеки `requests` и `firebase-admin`.
- База данных: Google Firebase Firestore (коллекция `gazelle_app`, документ `main_data`).
- Хостинг: Render.com (Web Service, Free Tier).
- Пингование сервера: UptimeRobot (раз в 5 минут по адресу `/sync`).

## Структура базы данных (Firestore)
Документ `gazelle_app/main_data` содержит поля:
- `cars`: массив объектов (машины).
  - Каждая машина имеет: id, name, glonassName (для связи), odometer (пробег), fuelLevel (топливо), manualBaseMileage (пробег при первой синхронизации), items (массив расходников).
- `log`: массив записей ТО.
- `drivers`: массив водителей.
- `trips`: массив рейсов.
- `expenses`: массив прочих расходов.
- `theme`: тема (light/dark).

## Интеграция с ГЛОНАССSoft (API v3)
1. **Авторизация:** POST `/api/v3/auth/login` с JSON `{"login": "...", "password": "..."}`. В ответе поле `AuthId` (токен).
2. **Список машин:** POST `/api/v3/vehicles/find` с заголовком `X-Auth: <токен>`.
3. **Пробег за день:** POST `/api/v3/vehicles/mileageAndMotohours` с телом `{"vehicleIds": [id], "from": "2026-11-17T00:00:00.000Z", "to": "..."}`. Берем `mileage` из `periods[0]`.
4. **Топливо:** POST `/api/v3/vehicles/getlastdata` с телом `{"vehiclesIds": [id], "includeSensors": true}`. Ищем в `sensors` элемент с `"name": "Топливо"` и берем его `rawValue`.

## Логика работы сервера (app.py)
1. Сервер авторизуется в ГЛОНАСС.
2. Получает список машин.
3. Читает текущие данные из Firebase.
4. Для каждой машины запрашивает дневной пробег и уровень топлива.
5. Считает новый пробег: `Текущий пробег = База (при первой синхронизации) + Дневной пробег`.
6. Обновляет документ в Firebase (перезаписывает массив `cars`).

## Важные нюансы
- Бесплатный Render засыпает через 15 минут. UptimeRobot (раз в 5 мин) не дает ему уснуть.
- ГЛОНАСС имеет лимит: 1 запрос в секунду. В коде стоит пауза `time.sleep(1)`.
- При первом запуске сервер запоминает текущий пробег как `manualBaseMileage`, чтобы не накручивать лишние километры при каждом запуске.
- В HTML-программе есть поля для ручного ввода (на случай, если ГЛОНАСС не отдал данные).
